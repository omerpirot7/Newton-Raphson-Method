# User Guide (1 page max)

## Purpose
This application teaches the Newton–Raphson method by showing each iteration on a graph and in a table.

## How to Use
1. Choose a function from the list.
2. Set initial guess (x0), tolerance, and max iterations.
3. Click Run to compute all iterations.
4. Use the slider or Step to view iterations one by one.
5. Read the status label to see convergence or failure.

## Tips
- Try different initial guesses to see convergence speed.
- If the derivative is near zero, the method may fail.

## Troubleshooting
- If the plot is empty, click Reset then Run.
- If status shows Failed, change x0 or increase max iterations.
